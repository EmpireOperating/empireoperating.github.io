# Empire Operating Website

A responsive, semantic recreation of the supplied Empire Operating references.

## Pages

- `index.html` — plain-language landing route with the protected original hero
- `contact.html` — direct email-first invitation
- `favicon-192.png` and `favicon.ico` — search/browser favicon using the Empire wreath emblem
- `apple-touch-icon.png` — iPhone and iPad home-screen icon

The retired information-rich About page is preserved in Git history and the
`production-before-simplified-home-2026-08-30` rollback tag rather than shipped.

## Preview

```bash
python -m http.server 4173 --bind 127.0.0.1
```

Then open `http://127.0.0.1:4173/`.
